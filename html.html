1. Basics

HTML is a markup language. It tells the browser what on the page is a heading, what is a paragraph, and what is a link. Each element is made of tags: an opening tag <p> and a closing tag </p>.

Code:

<p>Hello, world!</p>
 
<!-- Opening and closing tags -->
<p>Paragraph text</p>
Text between <!-- and --> is a comment. The browser ignores it.

2. Page structure

Every HTML page has the same skeleton. The head holds settings, the body holds what people see.

Code:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header><h1>My site</h1></header>
  <main><p>Content here</p></main>
  <footer><p>© 2026</p></footer>
</body>
</html>
Link style.css only once. Two links to the same file do nothing extra.

5. Links and images

HTML documentation on MDN

Code:

<a href="https://developer.mozilla.org/en-US/docs/Web/HTML" target="_blank" rel="noopener">HTML documentation on MDN</a>
 
<!-- Put photo.jpg in the same folder -->
<img src="photo.jpg" alt="Picture description" width="300">
 
<!-- A link to another page of your site -->
<a href="index.html">Go to the C++ lessons</a>
Always write alt text on images. It helps screen readers and shows if the picture fails to load.

6. Tables

TagMeaning
<p>Paragraph
<a>Link
<ul>Bulleted list

Code:

<table>
  <tr><th>Tag</th><th>Meaning</th></tr>
  <tr><td>&lt;p&gt;</td><td>Paragraph</td></tr>
</table>
To show < on the page, write &lt;. For > write &gt;.

7. Form

Code:

<form>
  <label for="name">Your name:</label>
  <input type="text" id="name" placeholder="Enter your name">
 
  <label for="level">Level:</label>
  <select id="level">
    <option>Beginner</option>
    <option>Intermediate</option>
    <option>Advanced</option>
  </select>
 
  <button type="button">Submit</button>
</form>
The button above shows a message with a few lines of JavaScript. A real form needs a server to save the data.
