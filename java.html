Add JavaScript to a page

JavaScript lives in its own file. Link it at the end of the body.

Structure

<script src="file-name.js"></script>

Example

<body>
  <h1>My page</h1>
  <script src="script.js"></script>
</body>
 
// script.js
console.log("Hello, world!");
Open the browser console with F12 to see what console.log prints.

Variables

A variable stores a value. Use const if it will not change, let if it will.

Structure

const name = value;
let name = value;

Example

const city = "Tashkent";
let age = 20;
age = 21;
 
console.log(city, age);

Data types

The main types are text, numbers, true/false, and empty values.

Structure

"text"        // string
123           // number
true / false  // boolean
undefined     // no value yet
null          // empty on purpose

Example

console.log(typeof "hello"); // string
console.log(typeof 42);      // number
console.log("JS".length);    // 2

Strings

Text has many helpful methods. Use backticks ` to put variables inside text.

Structure

`text ${variable}`        // template string
text.toUpperCase()        // CAPITAL LETTERS
text.includes("part")     // true or false
text.slice(start, end)    // cut a piece

Example

const name = "Aziz";
 
console.log(`Hello, ${name}!`);   // Hello, Aziz!
console.log(name.toUpperCase());  // AZIZ
console.log(name.includes("z"));  // true
console.log(name.slice(0, 2));    // Az

Operators

Operators do math and compare values. Use === to compare.

Structure

+  -  *  /  %      // math
===  !==  >  <  >=  <=   // compare
&&  ||  !              // and, or, not

Example

console.log(10 + 5);    // 15
console.log(10 % 3);    // 1
console.log(5 === "5"); // false
console.log(true && false); // false

If / else

Run code only when a condition is true.

Structure

if (condition) {
  // runs if true
} else if (otherCondition) {
  // runs if the second is true
} else {
  // runs if nothing above is true
}

Example

const score = 72;
 
if (score >= 90) {
  console.log("Excellent");
} else if (score >= 60) {
  console.log("Good");
} else {
  console.log("Keep practicing");
}

Loops

A loop repeats code.

Structure

for (start; condition; step) {
  // repeated code
}
 
while (condition) {
  // repeated code
}

Example

for (let i = 1; i <= 3; i++) {
  console.log("Round", i);
}
 
let count = 3;
while (count > 0) {
  console.log(count);
  count--;
}
If the condition never becomes false, the loop never stops. Always change something inside a while loop.

Functions

A function is a reusable block of code. It can take inputs and return a result.

Structure

function name(parameter1, parameter2) {
  return result;
}
 
const name = (parameter) => result; // arrow function

Example

function add(a, b) {
  return a + b;
}
 
const double = (n) => n * 2;
 
console.log(add(2, 3));  // 5
console.log(double(4));  // 8

Arrays

An array is an ordered list. The first position is 0.

Structure

const list = [item1, item2, item3];
 
list[0]            // read an item
list.push(item)    // add to the end
list.length        // how many items
list.map(fn)       // change every item
list.filter(fn)    // keep some items

Example

const fruits = ["apple", "banana", "cherry"];
 
console.log(fruits[0]);
fruits.push("mango");
 
const big = fruits.filter(f => f.length > 5);
console.log(big);

Objects

An object groups related data as key: value pairs.

Structure

const object = {
  key: value,
  key: value,
  method() {
    // code
  }
};
 
object.key

Example

const student = {
  name: "Aziz",
  course: "IT",
  greet() {
    return "Hi, I am " + this.name;
  }
};
 
console.log(student.name);
console.log(student.greet());

DOM and events

JavaScript can find elements on the page, change them, and react to clicks.

Structure

const element = document.getElementById("id");
 
element.textContent = "new text";
element.style.color = "red";
 
element.addEventListener("click", function () {
  // runs when clicked
});

Example

<button id="btn">Click me</button>
<p id="msg"></p>
 
// script.js
const btn = document.getElementById("btn");
const msg = document.getElementById("msg");
 
btn.addEventListener("click", () => {
  msg.textContent = "Button clicked!";
});
