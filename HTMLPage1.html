Your first program

Every C++ program starts in the main function.

#include <iostream>
using namespace std;
 
int main() {
    cout << "Hello, world!";
    return 0;
}

Variables and input

A variable stores a value. Each one has a type.

#include <iostream>
#include <string>
using namespace std;
 
int main() {
    int age = 18;          // whole number
    double price = 9.99;   // decimal number
    string name = "Aziz";  // text
    char letter = 'A';     // one character
    bool happy = true;     // true or false
 
    cin >> age;            // read from the keyboard
    cout << name << " " << age;
    return 0;
}
A double cannot hold text. Use string for names.

Decisions: if / else

Use if to run code only when a condition is true.

int score = 75;
 
if (score >= 90) {
    cout << "Excellent";
} else if (score >= 60) {
    cout << "Good";
} else {
    cout << "Try again";
}
Use == to compare, not =. A single = assigns a value.

Loops

A loop repeats code. This one prints the numbers 1 to 5.

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}
 
int n = 3;
while (n > 0) {      // repeats while the condition is true
    cout << n << endl;
    n--;
}

Arrays

An array stores several values of the same type. Counting starts at 0.

int marks[3] = {90, 75, 60};
 
cout << marks[0];   // 90 (first item)
 
int sum = 0;
for (int i = 0; i < 3; i++) {
    sum += marks[i];
}
cout << sum / 3.0;  // average
An array of size 3 has indexes 0, 1 and 2. Index 3 is outside the array.

Functions

A function is a reusable block of code.

int add(int a, int b) {
    return a + b;
}
 
int main() {
    cout << add(1, 5);   // 6
    return 0;
}

Classes

A class groups data and functions into one object.

class Student {
public:
    string name;
    int age;
 
    void hello() {
        cout << "Hi, I am " << name << endl;
    }
};
 
int main() {
    Student s;
    s.name = "Aziz";
    s.age = 18;
    s.hello();
    return 0;
}

Example 3: Calculator

#include <iostream>
using namespace std;
 
int main() {
    double num1, num2, res = 0;
    char math;
 
    cout << "enter num1: ";
    cin >> num1;
    cout << "enter num2: ";
    cin >> num2;
    cout << "enter symbol (+ - * /): ";
    cin >> math;
 
    if (math == '+') res = num1 + num2;
    else if (math == '-') res = num1 - num2;
    else if (math == '*') res = num1 * num2;
    else if (math == '/') {
        if (num2 == 0) { cout << "Cannot divide by zero"; return 1; }
        res = num1 / num2;
    }
    else { cout << "Unknown symbol"; return 1; }
 
    cout << "result: " << res << endl;
    return 0;
}

Tips for beginners

1. Every statement ends with a semicolon ;

2. You cannot declare two variables with the same name in one scope.

3. Give variables a value before you use them.

4. Read compiler errors from the top: the first error is usually the real one.

5. Type the examples yourself instead of copying. Then change them and see what breaks.
